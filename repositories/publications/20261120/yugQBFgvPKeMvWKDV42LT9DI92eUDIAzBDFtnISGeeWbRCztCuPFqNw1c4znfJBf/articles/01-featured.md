# arXiv Agent 与大模型研究简报｜2026-11-20｜精选

今天的研究把一个问题拆得更具体：智能体如何在长任务中保住有用经验，并在必要时做出可靠判断。值得对照阅读的是无反馈技能改写与有执行反馈的修订、摘要压缩与原始日志回查，以及推理教师向快速决策模型的迁移。

阅读推荐：🌟 值得关注；🌟🌟 建议阅读；🌟🌟🌟 优先精读。星标表示本期阅读优先级，不代表研究结论的可靠程度。

## 智能体系统与工具使用

### 摘要可以忘，原始日志仍能按需找回

Forget Freely, Grep Later: Lossless, Index-Free Memory for Long-Horizon LLM Agents

🌟🌟🌟

**问题**：上下文已经被压缩后，未来才显得重要的原始细节，能否仍然被可靠找回？

**结论**：完整日志与简单词面检索可显著改善精确回忆，但对摘要已经保住关键信息的任务，额外收益很小。

**新意**：让有损工作摘要负责继续执行，让无损外部日志负责保留细节，二者不再承担同一种职责。

长期智能体不得不压缩上下文，但压缩时通常还不知道后面会问什么。一段当时显得次要的工具输出，可能后来变成核对答案的唯一线索。与其要求摘要提前保住所有信息，这项研究选择把完整交互另外存下，等需要时再找。

系统仍会生成摘要，并从原始任务和摘要恢复工作上下文；同时，消息、工具调用、返回值以及摘要本身都追加到纯文本日志。第一次压缩之后，智能体获得正则搜索工具，可以按关键词查找，读取命中位置周围的内容，分页浏览，或只统计匹配数量。它不需要先抽取记忆，也不建立向量索引。

比较不只发生在提示层。作者用同一个九十亿参数模型，在相同数据与强化学习配方下分别训练五种策略。训练后的两个精确回忆任务，日志检索方案达到百分之九十七点四与九十五点三；在多问题研究中，相对仅摘要方案提高八点八个百分点。这支持一个朴素却重要的工程思路：存储保真和上下文经济可以分开实现。

不过，无损的是存下来的记录，不是模型寻找答案的过程。它仍需写出能命中相关文本的检索式。另一个以原因和状态变化为主的轨迹任务中，日志方案与摘要仅差零点九个百分点，且不显著。如果摘要已足够，额外回查只是成本。单一骨干的结果也尚不足以确定所有代理都能学会同样的搜索行为。

**编辑点评**：精确值与日志任务很适合这种设计；结果没有证明词面检索在语义改写、模糊线索或所有长期任务中优于结构化记忆。

**为什么值得读**：实现记忆系统时，可以先加入完整日志和可定位回查作为基线，再判断复杂索引是否提供了额外价值。

[阅读论文 PDF](https://arxiv.org/pdf/2611.25123)

### 先看技能哪条没被执行，再决定怎么改

Evolve Where It Matters: Coverage-Guided Self-Evolution of Agent Skills

🌟🌟🌟

**问题**：智能体按技能执行失败时，究竟应修正知识，还是让原有正确指令更容易被遵循？

**结论**：指令覆盖标签能帮助定位修订方向，在同任务有限次重试中改善成功率，但不等于新任务泛化。

**新意**：将遵循、未遵循与未触发三种指令状态，转成持续根因调查中的不同修订问题。

一份技能文档包含很多条件和动作。任务失败后直接让模型重写整份技能，容易把本来正确却没执行的指令当成无用内容，也可能原样保留已经被遵循但本身错误的规则。论文提出，修订之前应先看清指令在轨迹中怎样发生作用。

方法把可执行指令分成三类：条件出现且行为被遵循，条件出现但没有遵循，以及没有证据表明条件触发。覆盖裁判只看技能、任务和执行轨迹，不提前看到验证器反馈；持续存在的根因分析代理再结合执行结果提出解释。未遵循的规则要问如何让它可执行，已遵循的规则要问它是否写错，未触发的规则则要问是否与当前任务有关。

修订不是到生成文案为止。每一版都交给新的执行器运行，旧调查记录不会直接泄给执行器；一个维护器还提炼跨任务策略。作者在三个技能基准和三个执行器上报告，最终解决率为百分之六十四点七至七十点五，优于所比修订基线；删除覆盖信号会损失更多恢复成功的任务。

最需要保留的条件是，这里沿用针对同一任务修技能、最多五轮并在验证通过时停止的设定。因此，结果首先说明诊断信号能帮助当前任务修复，不能把它读成已经学到通用技能。标签本身也由模型生成，整套调查消耗更多词元，文档之外的脚本和资源并不参与演化。

**编辑点评**：有覆盖消融和同框架比较，但覆盖误标、重复运行成本与同任务适配边界都应与成功率一起看。

**为什么值得读**：可以把技能修改组织成有假设、有轨迹依据、有执行回归的实验，减少只凭失败感受整篇重写。

[阅读论文 PDF](https://arxiv.org/pdf/2611.25429)

## 大模型训练与对齐

### 局部混合层的收益，要到充分预训练后才看得清

Physics of Language Models: Part 4\.2, Canon Layers at Scale where Synthetic Pretraining Resonates in Reality

🌟🌟🌟

**问题**：标准榜单分数相近，是否意味着不同语言模型架构学到了同样的上下文能力？

**结论**：充分预训练能显现局部混合层的效率收益，但标准榜单仍会漏掉短上下文检索与简单两跳推理缺陷。

**新意**：把小型合成研究预测的差异放进规模更大、控制更严格的从头预训练实验。

评估架构时，一个常见做法是用较小模型和较短训练验证，再根据几个通用榜单决定是否继续投入。论文提醒，这里有两个不同问题：训练量是否足以让架构差异显现，测试题是否真的测到我们关心的能力。前者没有信号，不代表设计无效；后者分数相同，也不代表能力相同。

作者训练六十四个十三亿至八十亿参数模型，统一语料并尽量对齐结构，同时为各架构调学习率。局部混合层让相邻词元先交换信息，再进入主要计算模块。在八十亿参数条件下，达到相同知识问答准确率大约少用三成预训练词元。加入这些局部机制后，一种较简单的线性架构也能达到更复杂结构的通用榜单水平。

但作者随后换了测量角度：给模型一小段背景，让它找回其中的事实或连接两条信息。部分线性模型在通用榜单上并不差，却连五百词元背景中的检索也不稳定；简单两跳题对所测模型同样困难。这说明知识回忆、局部混合和上下文推理不是一个分数能够概括的能力。

这项研究最有价值的是配对训练和诊断题之间的互相校验。其结论仍依赖所测语料、模型规模和训练阶段，局部层配方还包含位置编码变化。不能把基础模型的缺陷直接当成所有指令模型或混合架构的结论。

**编辑点评**：配对控制和训练曲线提供较强证据；节省比例只对应特定指标与设置，不能等价为所有能力或训练成本降低三成。

**为什么值得读**：为架构研究提供两条检查线：扩大训练是否改变排序，换成直接的上下文诊断是否暴露榜单盲区。

[阅读论文 PDF](https://arxiv.org/pdf/2611.24963)

### 裁判的知识不易传给学生，类别盲点却会传过去

Blind Spots Travel, Knowledge Stays Home: What RL Inherits from an LLM Judge

🌟🌟🌟

**问题**：用模型裁判做奖励时，学生学到的是裁判掌握的知识，还是裁判愿意接受哪些类别的回答？

**结论**：在闭卷短答案实验中，裁判对类别的系统性怀疑会迁移成学生拒答，知识本身却可能仍被保留。

**新意**：通过手动修改少量奖励判决、限制拒答及强弱裁判对照，分离知识迁移与决策覆盖变化。

一个训练后更少胡说的模型，可能不是更知道答案，而是更不愿意回答某一类问题。如果只报告平均正确率和总体拒答率，这种覆盖范围的变化很容易被当成合理的谨慎。论文把裁判奖励的作用拆成单题知识和类别倾向，分别检验它们是否传给学生。

研究让学生回答事实题或表示不知道，正确回答得到奖励，拒答得到中间奖励。作者使用多种裁判、答案键和学生自身采样投票开展大量训练，并对少量训练判决做受控修改。最鲜明的例子是历史国家首都：裁判对这一类正确答案更怀疑，训练后的学生因此把这种倾向扩大成集中拒答。

只改变十二条相关训练答案的判决，就能让相应类别拒答率在很低与很高之间移动。更关键的是，禁止学生拒答后，它仍能答对大量原本知道的首都。这使“知识被忘掉”和“知识仍在但不再输出”成为可以区分的解释。较强裁判或答案键也未在新问题选择上带来想象中那么大的知识传递收益。

这里的证据支持一个具体警告，而不是所有模型裁判都无用。实验以短答案、低秩适配和固定拒答收益为主，类别探针也比较集中；开放生成中的情况没有被证明。学生自身投票方案同样需要检查阈值。真正可迁移的做法，是按问题类别审计奖励拒绝与训练后拒答，而非相信一个平均分足以说明覆盖没有缩水。

**编辑点评**：干预与禁止拒答对照较有说服力，但结论应限于所测任务和训练机制，不能解释为裁判知识完全无法迁移。

**为什么值得读**：为奖励模型审计增加类别覆盖这一维度，尤其适合发现平均准确率之外的系统性拒答损失。

[阅读论文 PDF](https://arxiv.org/pdf/2611.25191)

### 把推理教师的判断，蒸馏到一次前向里

GLiDE: A Fast, Calibrated Decision Model Distilled from Reasoning Teachers

🌟🌟🌟

**问题**：路由、筛选和评审需要快速输出概率，如何保留推理带来的判断力，又避免每次生成长链条？

**结论**：推理教师的软概率监督能训练单次前向决策模型，固定评测中兼顾质量、校准与延迟，但只能覆盖给定候选。

**新意**：将双向候选交互、专门选项读出和多教师渐进蒸馏组合，并扩展到多个模型规模。

生成模型可以一边思考一边决定答案，但大量系统需要的只是一个类型化选择：走哪条工具路线、是否需要升级处理、哪个候选更合适。如果每次都生成长推理，延迟和成本可能超过任务本身。论文研究的是把推理中的判断能力提前转移到一个直接输出选项概率的模型。

架构从现有混合语言模型出发，移除全注意力层的因果遮罩，让上下文、问题和候选相互读取；专门读出位置一次产生选项分布。训练先建立能推理的教师，再收集教师思考后的概率，用软目标而非只用最终标签监督，并通过多教师和更广决策任务继续后训练。

作者引用固定时点、由榜单维护者执行的隐藏评测：二百七十亿参数版本得到七十一点五二分，预期校准误差约百分之二，单卡中位延迟约九十三毫秒。另一个加入检查点平均和共享层循环的版本取得更高分，但它增加了计算，不能把较高分与基础版本延迟拼成同一性能点。

最关键的接口边界是候选集合。概率之和为一，只说明模型在列出的选项间分配判断，不说明正确答案一定在其中，也不保证换到实际业务分布后仍校准。循环深度、输入长度、硬件和批量都会改变延迟。它更适合作为带拒绝或升级路径的专用决策组件，而不是仅凭榜单就替换完整研究代理。

**编辑点评**：固定隐藏评测比只报公开题更有价值，但仍是作者引用的特定版测量；生产分布中的拒绝、校准与端到端任务收益需另测。

**为什么值得读**：能系统了解从推理示范到概率目标、再到快速读出的训练链，并据候选覆盖和升级策略判断适用位置。

[阅读论文 PDF](https://arxiv.org/pdf/2611.26509)

## 评测与安全

### 没有反馈的技能重写，会把专家细节越改越少

How Feedback-Free Self-Evolution Reshapes Agent Skills: A Systematic Study

🌟🌟🌟

**问题**：不给任务结果或外部判断，反复让模型优化专家技能，是否真的会得到更好技能？

**结论**：所测六个模型在三十轮无反馈改写后全部退步，优先丢掉的是它们自己不常写出的专家细节。

**新意**：把原技能与模型仅凭主题自写的技能比较，并用知识恢复和原位标记检验稀有内容的作用。

技能中的参数、例外和具体操作，读起来未必像一篇漂亮文章，却可能正是它比通用提示有用的原因。论文故意去掉任务执行、结果和人工评价，让模型只根据原技能和主题持续修改，观察这种看似免费的自我优化最终走向哪里。

作者让六个模型各自改写三十轮，再由同一模型使用这些技能完成任务。三个基准中，所有模型最终表现都低于原技能；在技能任务基准上，平均下降十四点六个百分点。改写并非每轮都单调变差，但总体趋势清晰，不能把偶尔一轮的小增益当成稳定改进。

为解释内容变化，作者让模型仅凭主题写出十份技能，用它们近似模型原本倾向提供的知识。原技能中这些自写版本都没有的内容，往往在改写时更早消失。把丢掉的这些内容补回，恢复的成绩比补回其他内容更多。于是作者尝试另一条路：不重写原文，只标记这些稀有知识并要求执行时特别注意，平均带来四点八个百分点的提升。

这项工作反对的是缺乏新证据却期待改写自动变好的假设。它并未测试所有有反馈修订，也未修改配套脚本；每个任务只使用预选的一份技能，多技能检索与组合仍在范围外。对实践者来说，更稳妥的启发是保留具体知识的来源与条件，只有当执行反馈指出问题时，才带着可验证目标改动它。

**编辑点评**：结果由确定性任务验证支撑，但“模型先验外知识”的度量仍依赖自写样本和模型判断，不能当成完整知识边界。

**为什么值得读**：对自动润色、摘要压缩和技能维护都有直接提醒：语言更顺不等于任务知识保存得更好。

[阅读论文 PDF](https://arxiv.org/pdf/2611.25534)
