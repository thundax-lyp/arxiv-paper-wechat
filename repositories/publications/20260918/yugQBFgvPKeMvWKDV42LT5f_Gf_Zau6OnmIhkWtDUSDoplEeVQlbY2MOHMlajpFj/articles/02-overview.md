# arXiv Agent 与大模型研究简报｜2026-09-18｜入选论文全览 1/2

本期最值得关注的是智能体系统开始从“能完成任务”转向“能解释、能复现、能约束”：网页搜索被拆成可诊断的全链路，工具调用增加解析与形式化安全边界，长程任务开始区分记忆、状态到达与最终完成，训练侧则更精细地分配轨迹信用和推理预算。星标表示本期阅读优先级：一星值得关注，二星建议阅读，三星优先精读；它不等同于结论可靠度，具体证据边界见每篇说明。

本期入选论文全览。

## 智能体系统与工具使用

### 让智能体自动搜索预训练数据筛选规则

AutoData: Agentic Search for Pre-training Data Selection

🌟🌟🌟

把预训练数据筛选纳入智能体自动研究闭环，让智能体直接搜索可执行的数据选择算法。其做法是在文档特征上搜索评分、分层和随机选择程序，并用小型代理模型反馈迭代。数百步隔夜搜索得到优于人工管线的配方，并在 1.3相关方法 以内多尺度迁移。只验证一个基础语料和较小模型，代理目标与昂贵的 相关方法 标注特征限制通用性。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19754)

### 长期对话记忆的关键不是多读，而是按需找够证据

JustMem: Just-Enough Memory Access for Long-Term Conversations

🌟🌟🌟

把长期对话记忆访问分解为发现广度与阅读保真度，按问题只取足够证据。其做法是以原子记忆为底座，分别用查找、组合和回放处理局部、分散与细节敏感证据。在 长期记忆基准 与 长期记忆评测 上取得最高平均准确率和召回率，并显著减少生成模型 词元；增强长期记忆基准 也更稳健。系统成本分析主要计算生成 词元，未覆盖全部检索和存储开销。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19877)

### 用可回滚技能图约束智能体从错误中学习

SkillAA: Attribution-Guided Skill-Graph Updating with Targeted Validation and Rollback

🌟🌟🌟

针对失败后直接修改技能导致路由模糊和回归的问题，统一技能选择、归因、更新与回滚。其做法是相关方法 用可寻址技能图定位最小修复对象，并通过局部门和全局门分层验证后原子提交。三个基准和多个模型家族中主设置平均成绩均为最高，消融支持结构化节点、关系和局部回归控制。图规模、任务范围与重复次数有限，全局门的留出收益具有模型依赖性。

[阅读论文 PDF](https://arxiv.org/pdf/2609.20455)

### 自动研究如何找出更省上下文的编码智能体框架

SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness

🌟🌟🌟

用递归自动研究在多环境中搜索可迁移的编码智能体框架机制，重点降低长轨迹 词元 成本。其做法是筛选出执行、上下文压缩、观察处理和委派阅读四类机制组成 相关方法。相关方法 上性能可比而 词元 流量下降 44.7% 至 49.0%，成本约降三分之一，并跨两种模型迁移。仍是预备性 相关方法 证据，机制选择与评测环境覆盖有限。

[阅读论文 PDF](https://arxiv.org/pdf/2609.20519)

### 编码智能体的上下文、规划与工具接口应按能力配置

An Empirical Study of Harness Design for Coding Agents

🌟🌟🌟

以固定执行循环控制研究编码智能体的上下文管理、规划和动作空间各自如何影响表现。其做法是跨四模型、两基准、176 个匹配设置，对五种上下文策略、四档窗口和组件消融做因子比较。紧窗口下上下文管理收益最大；规则省略后再摘要最省成本；规划和工具接口的价值随模型能力变化。动作空间是捆绑干预，规划仅一种实现，部分组合未做完全因子实验。

[阅读论文 PDF](https://arxiv.org/pdf/2609.20804)

### 跨越数天任务的智能体需要怎样的运行底座

An Architecture for Long-Horizon Agents: Levels, Ticks and Cascaded Intelligence

🌟🌟🌟

面向持续数天或数周、跨上下文与进程的长期智能体，提出可持续运行的分层架构。其做法是以时间尺度分层摘要、时钟式 相关方法 和失败后升级的级联智能构成长时运行底座。十天复现实验保持跨会话线程，并让早期写入的运行知识影响后续行为。证据主要来自一次研究复现，缺少多任务、多模型和对照消融。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19519)

### 网页智能体如何把成功轨迹变成可复用技能

EconSkills: Studying Skill Transfer and Retrieval for Web Agents on Live Economic Data

🌟🌟🌟

研究网页智能体如何把成功轨迹蒸馏为可复用程序技能，并区分已知匹配下的迁移与技能库检索。其做法是将轨迹抽象为含适用范围、步骤、验证与恢复动作的参数化操作规程。已知匹配技能提高成功率并减少步骤；大库检索总体仅与无技能基线相当，覆盖任务受益更明显。结果清楚揭示技能本身有效，但选择器和覆盖不足会抵消收益。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19523)

### 用低成本树搜索加速编码智能体的自我改进

Self Improvement via Fast Tree-search

🌟🌟🌟

降低编码智能体递归自改中评估候选补丁的主要成本。其做法是快速树搜索框架 用成对模型裁判与 成对偏好强度模型 强度分数引导轻量树搜索，只对优先节点做昂贵任务评测。相关方法 上以更少 相关方法、时间与 接口 成本超过既有自演化框架，并跨骨干迁移。中间信号依赖模型裁判，错误偏好可能引导搜索，适用面仍集中于编码。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19526)

### 企业智能体如何持续发现和修订隐藏业务规则

Continual Enterprise World Model Discovery in Dynamic Systems

🌟🌟🌟

研究企业智能体如何通过交互持续发现、修改、增加和淘汰隐藏业务规则。其做法是相关方法 在 企业服务平台 四个连续版本中测试 相关方法 构建并携带可执行世界模型。600 个动作上世界模型预测优于逐题查规则，修改和新增成功，但所有骨干都未学会规则退休。环境只有一条系统谱系且每次仅改一条规则，并允许读取规则定义。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19551)

### 从逐次追踪走向跨运行的智能体语义剖析

AgentPProf: Semantic Profiler for Long Horizon AI Agents

🌟🌟🌟

把系统性能剖析引入长程智能体，用跨运行聚合回答失败、风险和预算归因问题。其做法是以语义操作栈替代代码调用栈，并递归分割轨迹，输出兼容 性能剖析格式 的剖面。在 相关方法 达到 0.764 聚类调和指标 调和平均指标，并在三个定位基准上将 相关方法 最高提高 56%。跨项目、在线控制和更稳定的意图状态模型仍待扩展。

[阅读论文 PDF](https://arxiv.org/pdf/2609.20301)

### 让全双工语音助手可靠调用工具的前后端分工

A frontend-backend architecture for tool calls in full-duplex speech models

🌟🌟

为全双工语音模型增加外部工具调用，同时尽量保留自然轮次、中断与低延迟。其做法是前端学习发出委派标记并转交文本后端，工具结果再以轻量预填回注语音前端。单轮工具调用召回率 92% 至 97%，无关调用拒绝准确率 81.2%，更大后端提升代理基准表现。评测以单轮工具调用为主，复杂多轮任务和真实噪声环境仍需更多证据。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19334)

### 把线上失败变成可控技能补丁的多智能体运维

FINSKILLOPS: A Self-Evolving Multi-Agent System for SEC Filing QA

🌟🌟

将上线后的 相关方法 问答错误转成受控技能补丁，并用回归门管理技能生命周期。其做法是多智能体诊断证据与错误类型，候选技能经目标验证、保护样例和负控后才升级。六个金融问答基准平均最好；12 轮运维中仅 33 个候选的 6 个获准，监控错误率由 20% 降至 12.5%。自动裁判与数据隔离记录不完整，演化过程同时改变路由和诊断，难以隔离技能文本贡献。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19680)

### 不同智能体工作负载为何需要不同资源调度

Not All AI Agents Are Equal: Characterizing Resource and Performance Dynamics

🌟🌟

刻画检索、网页搜索和编码智能体的远端推理与本地工具资源混合瓶颈。其做法是测量不同并发、模型延迟与容器 相关方法 配置，再据任务类型设计准入和 相关方法 分配。相关方法 敏感任务延迟最高改善约 5.4 倍，多任务平均延迟下降约 32%。任务与部署栈数量仍有限，在线调度器尚未完成。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19947)

## 大模型推理与规划

### 让模型按题目难度决定该思考多久

When2Think: Learning Difficulty-Aware Length Control for Efficient Hybrid Reasoning Models

🌟🌟🌟

把推理效率定义为按实例难度分配计算，而非统一压缩思维长度。其做法是相关方法 用预计算正确率与 词元 统计塑造难度感知奖励，并结合验证奖励训练混合推理策略。二〇二四年美国数学邀请赛 的 相关方法@3 提高 10 点且 词元 降 27.9%，多数学数学基准改善准确率—成本权衡。主要基于数学任务与参考统计，跨领域和参考分布变化的适应性未知。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19671)

### 强化学习为何难把分解技能自动组合起来

Compositional Reasoning in Language Models under Reinforcement Learning Post-Training

🌟🌟🌟

研究强化学习后训练能否把分解技能组合成新任务，发现训练方向存在明显不对称。其做法是用依赖图定义三层组合复杂度，并在数据结构任务及多工具调用先导实验中验证。只训练分解技能难迁移到组合任务，组合任务训练反而较易回到分解任务。主体是受控合成任务，真实工具调用只属小规模先导证据。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19465)

### 让验证反馈不仅选答案，还能修复和生成更好的答案

LLM-as-an-Improver: Turning Verification into Better Candidates

🌟🌟

把验证器从只排序候选扩展为用反馈主动修复和生成更强候选。其做法是验证修复再选择流程 保留初始胜者，并条件生成胜者修复、次优修复和新路径，再过滤重复与无效答案重选。两模型八基准的 16 个设置中胜 9、平 4、负 3；初始候选全错时仍能救回部分答案。收益并非所有设置稳定，且额外生成增加推理成本。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19515)

## 检索增强生成与知识检索

### 对话式智能体如何搜索网页：调用、查询、来源与引用的全链路

Characterizing Web Search by Conversational LLM Agents: From Search Decisions and Strategies to Results and Responses

🌟🌟🌟

从是否搜索、如何构造查询、搜索结果偏好到最终回答，端到端刻画四个平台的对话式网页搜索。其做法是结合真实用户交互与同平台模型 接口 的受控重放，分析调用、查询、来源和引用支撑。更频繁搜索不等于更好回答；平台存在查询与来源差异，部分结论虽有结果支撑却未引用。专有平台内部链路不可见，观察到的差异可能混合模型和产品框架效应。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19244)

### 面向历史档案的可追溯智能体检索

TRACE: Accountable Agentic Retrieval for Source Discovery in Digital Archives

🌟🌟

面向 相关方法 噪声历史档案，强调可追溯的来源发现而非只生成答案。其做法是相关方法 将问题分解到不同语料，多通道融合检索，并以接受、拒绝、待定和跨子问题确认排序。在 1752 个法语历史问题上达到 前十召回率 0.856、平均倒数排名 0.653，超过稀疏、稠密、图式与智能体 检索增强生成 基线。应用集中于一个历史档案项目，但已有 24 名研究者的内部部署证据。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19897)

### 排障检索应匹配案例的当前阶段，而非整份工单

RAFT: A Stateful Retrieval-Augmented Framework for Troubleshooting Agents

🌟

针对企业排障案例具有阶段状态这一特点，将历史工单从静态文档改为状态链检索。其做法是相关方法 把已关闭案例抽象成时间线条目，在条目级匹配当前状态并返回锚定后的父案例轨迹。合成基准各阶段的 案例命中率 都优于普通 检索增强生成 与 图结构检索增强生成，真实 相关方法 重复组提供方向性迁移证据。主数据为中等规模合成集，真实审计仅 30 组，且未评估最终诊断或工程效率。

[阅读论文 PDF](https://arxiv.org/pdf/2609.20754)

## 多智能体与协作

### 多智能体何时胜过单智能体，何时反而拖后腿

Rethinking Multi-Agent Collaboration: When More Is Less

🌟🌟🌟

系统回答多智能体何时优于单智能体：稀疏依赖的长任务受益，紧耦合顺序任务反而更适合单智能体。其做法是相关方法 在执行中增量生长任务图，并按语义依赖按需传递上下文。四个长程基准显示其在性能和上下文成本间取得较好平衡，增加智能体数量或递归深度并不稳定增益。结论依赖所选基准与模型，任务依赖结构的自动估计仍可能出错。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19759)

### 隔离的模型实例能否用自然语言建立隐蔽协作信号

For Your Eyes Only: Evaluating Coordination Between Isolated Language Model Instances

🌟🌟🌟

检验隔离的同模型实例能否仅凭共享预训练和任务指令，在自然语言中建立隐蔽协作信号。其做法是构建发送者—接收者双遍成功率游戏，并加入显式约束、检测过滤、破坏与跨模型条件。七模型、300 词对中多数模型受约束后协调崩溃，但一款前沿模型过滤后仍近乎完美。任务明确告知双方协作目标且仅限英语词对，不能直接证明普通部署会自发出现同类行为。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19504)

## 大模型训练与对齐

### 从动作归因到轨迹权重：智能体强化学习的双轴优化

Dual-Axis Policy Optimization for LLM Agents: Bayesian Feedback Attribution and Trajectory Mass Normalization

🌟🌟🌟

将智能体强化学习拆为轨迹内反馈归因与轨迹间目标聚合两个独立优化轴。其做法是相关方法 用贝叶斯反馈归因重分配动作学习质量，并用轨迹质量归一化平衡整条轨迹。在 家庭环境基准、网络购物基准 与 搜索问答基准 上同时改进 组相对策略优化 和 细粒度策略优化，多个模型尺度均有增益。主要集中在三类标准环境，尚未覆盖开放式真实工具链。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19830)

### 让任务生成、工具执行与验证器共同进化

UnifiedPlayers: Enhance Tool-Integrated Reasoning in Agentic Reinforcement Learning

🌟🌟🌟

让任务规划、工具执行和可执行验证器三个角色共同进化，避免静态验证与自一致性共享错误。其做法是相关方法 为三类玩家设计独立奖励，并在扰动轨迹与 相关方法 沙箱反馈下交替 组相对策略优化 更新。两种骨干、十二个推理基准均超过最强基线；验证器对抗检测准确率 84.2%。当前工具主要为 相关方法，训练成本和更开放环境稳定性仍需检验。

[阅读论文 PDF](https://arxiv.org/pdf/2609.20089)

### 让蒸馏教师在该退出时自动退出

RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning

解决智能体在轨蒸馏中教师不可靠且持续监督后期有害的问题。其做法是先训练带技能教师，再联合 组相对策略优化 与蒸馏训练无技能学生，并在差距停滞且能力达标时自动退休教师。1.5相关方法 至 7相关方法 模型在 家庭环境基准 与 网络购物基准 均超过纯 相关方法、持续联合训练和技能教师。实验集中于两个经典环境，退休阈值和跨任务稳定性仍待验证。
