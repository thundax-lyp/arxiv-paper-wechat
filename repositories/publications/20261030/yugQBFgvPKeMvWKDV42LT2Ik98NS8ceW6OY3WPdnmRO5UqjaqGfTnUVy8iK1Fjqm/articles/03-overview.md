# arXiv Agent 与大模型研究简报｜2026-10-30｜入选论文全览 2/2

本期关注智能体如何把证据变成可靠行动：网页环境怎样复建，反馈怎样改变重试与模型选择，指令与数据如何分离，以及形式证明能核验到哪里。另有技能复用、多智能体成本和科研评测工作，尤其值得留意高分、共识与真实可靠性之间的距离。

本期入选论文全览。

## 应用与基准

### 披露审查智能体：改好文件之前先发现缺项

FilingLoop: Evaluating and Evolving LLM Agents for Corporate Disclosure Review and Revision

🌟

披露审查智能体先要发现未明说的缺项，再补事实和改文件。该基准以380个历史任务组织审查修改，并把已锁定评分变为后续案例的程序指引，要求履行率从24.28%升至27.96%。改进来自单一顺序且依赖模型裁判，不能视为监管通过率。

[阅读论文 PDF](https://arxiv.org/pdf/2610.37905)

### 财报预测点估计接近共识，区间却偏窄

EPSBench: Benchmarking LLM Agents for Earnings Forecasting

🌟🌟

财报预测应同时看点估计与不确定区间。作者让智能体提交有证据的收入费用假设，再由共享会计计算器算出每股收益。三个模型点误差与分析师共识差异未检出，但六模型声称80%的区间实际仅覆盖37%至70%；无显著差异不是等效证明。

[阅读论文 PDF](https://arxiv.org/pdf/2610.38293)
