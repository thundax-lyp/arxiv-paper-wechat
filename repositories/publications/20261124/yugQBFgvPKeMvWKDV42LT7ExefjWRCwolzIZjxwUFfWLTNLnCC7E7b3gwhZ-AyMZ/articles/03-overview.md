# arXiv Agent 与大模型研究简报｜2026-11-24｜入选论文全览 2/2

本期关注模型与执行框架的分工：实时代理如何跟上环境，研究代理怎样保存试验，以及工具只返回部分结果时如何复核。另外几项工作讨论了把长任务拆成短调用，以及如何衡量安全评测和蒸馏带来的差异。

本期入选论文全览。

## 应用与基准

### 让金融建模训练从可执行挑战中生长

FinEvo: Recursive Self-Improvement for Long-Horizon Financial Modeling

🌟🌟

金融表格任务可用程序检查结果，但任务说明本身也可能有漏洞。研究让同一模型生成、演化并求解挑战，再利用执行反馈训练。外部财务表格基准的整题成功率从约百分之十三升到十九。目前只展示一轮生成和学习，反复迭代是否继续提升还有待观察。

[阅读论文 PDF](https://arxiv.org/pdf/2611.28239)

### 先把异常写成可检验目标，再自动挑检测器

SMAD: A Semantics-Guided Multi-Agent Framework for Unsupervised Time-Series Anomaly Detection

🌟🌟

自动挑选时序异常检测器之前，先要明确什么算异常。研究让智能体把目标写成可测算的语义要求，再用合成干预核对候选流水线的响应。单变量和多变量测试均有改善，且模型开销低于所测通用编码代理。收益依赖合成异常能否反映真实故障。

[阅读论文 PDF](https://arxiv.org/pdf/2611.28348)
