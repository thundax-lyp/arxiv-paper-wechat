# arXiv Agent 与大模型研究简报｜2026-09-18｜精选

## 大模型推理与规划

### 让模型按题目难度决定该思考多久

When2Think: Learning Difficulty-Aware Length Control for Efficient Hybrid Reasoning Models

🌟🌟🌟

**问题**：统一长度惩罚会让简单题少想，却也迫使难题提前停止；固定路由则难以随具体题目调整，推理效率因此不是单纯压缩 词元 的问题。

**结论**：按实例难度塑造推理预算后，模型能在简单题减少无效思考、在难题保留更长推理；二〇二四年美国数学邀请赛 的三次采样通过率提高 10 个百分点，同时平均 词元 降低 27.9%。

**新意**：用预先统计的题目正确率和 词元 消耗构造难度感知奖励，让同一模型学习在直接回答与展开推理之间连续分配计算，而非硬切两种模式。

大推理模型的浪费并不只是回答太长，而是把计算放错了地方：简单题反复验证，难题却在固定预算下被截断。相关方法 将这个问题改写为逐题分配资源。训练前先估计每道题在参考策略下的正确率和 词元 使用，再把这些统计转成奖励塑形信号；容易题若能短答正确便获得更高回报，困难题则不会因为使用较长推理自动受罚。该信号与可验证答案奖励、批内标准化优势结合，在不训练价值模型的情况下优化混合推理策略。多个数学基准显示，方法改善了准确率与成本的折中，而不是简单用准确率换速度。二〇二四年美国数学邀请赛 上通过率和 词元 同时向好，二〇二五年美国数学邀请赛 也高于压缩和纯路由基线。更值得注意的是，它把“何时思考”和“思考多久”统一为同一个连续控制问题，为服务系统中的动态预算提供了训练目标。

**编辑点评**：难度监督依赖预计算参考统计，实验几乎都在可验证数学题上；面对开放问答、工具调用或分布漂移时，难度估计是否仍可靠尚未证明。

**为什么值得读**：它把推理成本优化从统一截短推进到实例级资源调度，适合启发动态预算、早停和按难度计费的推理系统设计。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19671)

## 检索增强生成与知识检索

### 对话式智能体如何搜索网页：调用、查询、来源与引用的全链路

Characterizing Web Search by Conversational LLM Agents: From Search Decisions and Strategies to Results and Responses

🌟🌟🌟

**问题**：现有研究常只测最终答案，难以知道对话式智能体究竟在何时决定联网、怎样改写查询、从哪些来源取材，以及引用是否真正覆盖了结论。

**结论**：四个平台的搜索触发和查询策略差异明显；搜索更频繁并不自动带来更好的回答，而且部分有检索依据的主张没有得到显式引用。

**新意**：把网页搜索拆成调用决策、查询构造、结果来源和回答落地四个连续环节，并同时使用真实交互与受控重放观察同一链路。

对话式搜索不是一次检索调用，而是一串相互依赖的决定。智能体先判断参数知识是否足够，再选择查询词、决定是否继续搜索，最后把若干页面压缩成回答。任何一环偏差，都可能在最终文本里被流畅表达掩盖。论文将这条链路拆开，对聊天平台的真实用户轨迹做观察分析，又用相同平台的模型接口重放样本，以区分用户分布与模型行为。结果显示，不同平台对同类问题的联网倾向和查询复杂度并不一致，平台搜索引擎还会返回带有自身偏好的来源域名。更重要的是，较高的搜索调用率没有稳定转化为更高回答质量；即便回答大体受搜索结果支撑，仍存在使用结果却不展示引用的主张。对检索智能体设计而言，这意味着优化目标不能只盯着是否调用搜索或召回了多少页面，还要检查查询是否覆盖问题、来源是否多样，以及每个关键结论能否追溯到公开证据。

**编辑点评**：真实平台内部排序、隐藏提示和推理轨迹不可见，因此观察到的差异混合了模型、搜索引擎与产品框架。自动裁判虽有人类抽查，仍可能遗漏细粒度引用错误。

**为什么值得读**：它提供了一套比“联网率”和“最终分数”更有诊断力的评测视角，适合用来设计搜索代理的日志、引用检查和端到端回归测试。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19244)

## 评测与安全

### 用形式化验证为编码智能体的输出加上机器可检验的安全保证

MAGS: Multi-agent Auto-formalization Guarantees Safety for Agentic Outputs

🌟🌟🌟

**问题**：编码智能体能快速生成大量程序，但测试、静态分析和模型审查都难以覆盖所有边界条件，传统形式化验证又需要昂贵的人工规格与证明工程。

**结论**：在冻结安全语义和接口规格的前提下，多智能体流程为 220 个跨 图形处理器并行程序、终端与机械臂任务生成了可执行且通过 形式化验证语言 检验的程序；但规格覆盖不足时，证明并不等于真实语义安全。

**新意**：先由人审计并冻结可复用领域语义，再让生成、翻译和修复智能体只能围绕该规格工作，从流程上阻止系统通过弱化安全定义来获得证明。

这项工作的关键不是让模型自己声称代码安全，而是把安全边界移交给确定性验证器。系统先为领域接口和安全要求建立经人工审计的 形式化验证语言 语义，并在处理具体任务前冻结；之后，多个智能体把候选程序翻译到验证友好的中间表示，根据验证器给出的反例修复，再编译回可执行代码。这样，生成智能体不能为了让证明通过而临时改写规则。实验覆盖一百个 图形处理器并行程序 内核、一百个终端脚本和二十个机械臂任务，所有样本都获得了针对冻结规格的非平凡安全证明，并另外检查功能保持和安全性。结果同时暴露两类边界：终端程序中，未被形式化的库语义会留下缺口；机械臂任务中，过粗的规格可能允许“什么也不做”这类安全却无用的修复。因此真正可复用的资产不是某次证明，而是被审计、版本化且覆盖充分的领域语义。

**编辑点评**：百分之百通过只说明程序满足已写入的规格。自动形式化若漏掉真实意图，验证器会忠实证明一个不完整命题；功能评测和规格审计仍不可省。

**为什么值得读**：它把智能体安全从概率性的测试置信推进到可检查契约，也清楚展示了形式化系统最容易被误读的地方：证明强度永远受规格强度约束。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19391)

### 工具调用幻觉为何必须在权限门控之前拦截

Closed-World Resolution Against Tool Hallucination in LLM Agents

🌟🌟🌟

**问题**：工具安全系统通常默认调用指向真实工具且参数属于已声明模式；一旦模型虚构工具、字段或跨服务器借用参数，后续权限门控甚至没有可判定的对象。

**结论**：十个托管模型在单注册表测试中产生 322 次真实幻觉，模型上下文协议 合并命名空间又出现 154 次；一个位于所有权限门之前的封闭世界解析层可以拒绝这些调用，但对模式上合法的错误工具选择无能为力。

**新意**：把工具幻觉从“选错工具”中独立出来，证明解析必须先于因果权限门，并为多服务器 模型上下文协议 的冲突、遮蔽、陈旧定义与跨服务器借用建立第二套分类。

很多代理防线从权限开始思考：某个工具是否允许调用、参数是否触及敏感资源、执行前是否需要确认。但这些机制都暗含一个前提——模型输出的工具和字段确实存在。论文指出，虚构调用并不是任何权限门作出的决定，因此把它直接交给门控层，会形成结构性盲区。作者提出的解析阶梯只做很朴素的两件事：检查工具是否属于当前注册表，检查参数是否符合签名；重要的是它在调用链中的位置，而不是算法复杂度。十个模型在原始 结构化调用 和模式约束接口上接受压力测试，结果表明调用表面比模型规模更决定风险：无约束接口的幻觉率明显更高，大模型也不能自动消除问题。扩展到 模型上下文协议 后，多个服务器合并命名空间又引入同名冲突、工具遮蔽和跨服务器参数借用，单一注册表不足以表达全部边界。解析层能拦住不存在或不合模式的调用，但无法识别“参数形式合法、语义上却借错对象”的残余风险，后面仍需要选择器和权限策略。

**编辑点评**：每个模型和接口的探针数量不大，误拒率还没有用独立诚实调用语料验证；“全部拒绝”不能被外推为完整工具安全方案。

**为什么值得读**：它给出了一个极易落地却经常缺位的架构原则：先解析存在性和签名，再做权限与策略判断，并提醒 模型上下文协议 主机必须显式处理跨服务器命名空间。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19425)

### 强化学习究竟让智能体更会到达，还是更会收尾

Reach or Solve? Attributing Agentic RL Gains with Checkpoint Handoffs

🌟🌟🌟

**问题**：强化学习后的智能体通常只按最终成功率与监督微调版本比较，但两者会因早先动作进入不同状态，终点差异无法说明提升来自更会探索还是更会完成。

**结论**：在两个基准和两条独立训练管线中，把同一已到达状态交给另一检查点后，强化学习对到达和完成都有可分离贡献；只比较双方都到过的状态甚至会翻转结论。

**新意**：相关方法 不重新训练，而是克隆一个检查点真实到达且由环境验证的状态，再交给另一个检查点继续，从而交叉估计到达能力与解题能力。

长程智能体会写下自己的下一步输入：前一个动作改变环境，后一个决策面对的状态也随之变化。因此，用端到端成功率比较监督微调与强化学习检查点，会把两件事混在一起：谁更容易走到接近成功的位置，以及到了相同位置后谁更会把任务做完。论文设计的检查点交接协议先让一个策略运行到环境确认“距成功还剩固定步数”的状态，克隆该状态，再把历史交给另一个已发布检查点继续。将到达者和完成者在两种检查点之间交叉，就能估计 到达能力 与 完成能力。五个条件中的交互项都为正；在 家庭环境基准 的精确回放中，强化学习版本更常抵达可解前沿，也更常从完全相同的状态完成任务。论文还指出，仅保留两种策略都到过的状态会引入结果条件选择，在其数据中甚至改变效应方向。

**编辑点评**：方法要求环境状态可克隆、历史可由另一检查点接续，因此不适用于所有现实工具和不可逆外部系统；目前证据仍集中于两个基准。

**为什么值得读**：它提供了比终点成功率更可解释的强化学习评测：训练团队能判断收益来自探索、收尾还是两者协同，从而更准确定位数据和奖励设计问题。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19636)

## 应用与基准

### 长期陪伴智能体真的理解人的生活规律吗

SIMLIFE: Pattern Understanding for Long-Horizon Human-Agent Partnership

🌟🌟🌟

**问题**：长期陪伴智能体不仅要记住事实，还要从数周生活记录中推断习惯为何形成、何时改变，并在反事实和噪声下更新判断；现有短对话基准测不到这一层。

**结论**：当前模型常能做表面预测，却依赖频率而非条件规则，面对习惯变化时也难以及时修订；这使长期记忆、个性化和规划之间出现明显能力缺口。

**新意**：用可扩展家庭生活模拟生成超长多模态轨迹，同时保留真实动作规则，构造直接、反事实、含噪和逆向四类问题来区分记忆与规则理解。

长期智能体最容易制造一种错觉：它能复述用户过去做过什么，于是看起来像理解了用户。相关方法 把这个错觉拆开。平台模拟数十天的家庭生活，记录视觉观察、动作日志和带音频的对话，再用隐藏行为规则生成问题。模型既要回答常规预测，也要处理反事实、噪声证据和从结果反推规则，因而不能只靠检索一个相似片段。基准包含 106 个事件，每个事件平均跨越约三十九个游戏日，总计 1439 个问答。实验显示，前沿模型会随着观察增加而提高表面预测，但常用频率统计替代“如果—那么”的规则推理；当行为规律改变时，旧模式又容易持续干扰新判断。人类判断在平衡准确率、正类识别和概率校准上仍明显领先。这个结果说明，长期上下文长度只是入口：真正困难的是从证据形成可检验假设、发现变点，并决定哪些旧记忆应保留、降权或覆盖。

**编辑点评**：生活轨迹来自模拟器，对话含合成成分，不能直接代表真实个人数据中的噪声、隐私和社会复杂性；它更适合衡量机制，而非宣称已解决陪伴。

**为什么值得读**：它给记忆系统提出了更严格的验收标准：除了事实召回，还应测规则归纳、反事实、变点适应和概率校准，这些指标直接影响长期代理的可信度。

[阅读论文 PDF](https://arxiv.org/pdf/2609.19610)
