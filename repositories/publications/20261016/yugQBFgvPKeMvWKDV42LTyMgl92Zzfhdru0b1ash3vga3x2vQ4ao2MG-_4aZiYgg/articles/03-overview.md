# arXiv Agent 与大模型研究简报｜2026-10-16｜入选论文全览 2/2

本期关注智能体系统的证据边界：工具执行如何独立验收，记忆内容是否真正贡献收益，删除后是否仍能重建秘密，以及协作训练怎样公平比较计算预算。另有上下文工程、技能演化、研究规划与客户交付的实证诊断。以下结果来自论文报告与正文审读，尚未独立复现实验。

本期入选论文全览。

## 评测与安全

### 上下文工程是否有效，要看它修复哪一种行为

Same Context, Different Agents: A Behavioral Study of Semantic Layers, Orchestration and Compaction in Data Agents

🌟🌟🌟

编排、工作层和上下文压缩并非叠得越多越好。论文在固定模型、工具与执行预算下比较八种组合，发现收益取决于原有行为：编排能纠正过早作答，却让本来会调查的模型平均下降约5个百分点。结果支持先诊断再加组件；它覆盖的是资料问答和代表性设计，尚不构成所有场景的配置答案。

[阅读论文 PDF](https://arxiv.org/pdf/2610.20959)

### 删除记忆条目后，秘密仍会从旁支证据中泄露

MemCut: Every Secret Leaves a Trail in the Long-Term Memory of LLM Agents

🌟🌟🌟

记忆删除若只移除直接提到秘密的条目，旁支证据仍可能把答案拼回来。论文把456个秘密分散到关联线索中，在五种记忆系统、四种读者模型上测试；追加有限删除后，仍有39%至76%可被推断。它揭示局部遗忘的攻击面，但实验限定了文本构造与删除预算，不能据此断言全部擦除策略失效。

[阅读论文 PDF](https://arxiv.org/pdf/2610.21405)

### 技能继续优化后，最好的版本可能已经过去

Evolving Together, Failing Apart: The Skill-Policy Co-evolution Trap in Self-Improving Agents

🌟🌟

技能优化不能只看最终版本相对起点的涨幅。论文复测四类方法的演化轨迹，发现末期成功率可比各自峰值低5至13个百分点，抵消过半已获收益。它还检查等价改写和污染抵抗，提醒系统保存并复验历史最优版本。不同方法的骨干与配置不同，这些结果适合诊断漂移，不宜直接排优化器名次。

[阅读论文 PDF](https://arxiv.org/pdf/2610.20845)

### 科学研究转向判断，可能被选项线索掩盖难度

Sci$Π$vot: Benchmarking Principal-Investigator Judgment at Pivotal Moments of Scientific AutoResearch Agents

🌟🌟

研究智能体何时应改变方向，比生成一段计划更难测。本文从二十六个项目抽取248个纠偏决策，让模型选择下一步，最佳结果63.5%，低于人类73.4%。只给候选选项反而改善部分模型，暴露了题面线索的影响。它衡量转向识别，尚不能证明自主发现问题、提出新路线的能力。

[阅读论文 PDF](https://arxiv.org/pdf/2610.21082)

### 工具调用失败，未必应该修补模型的规划

ToolBottleneckBench: Measuring Tool-Agent Performance under Controlled Pressures and Fixed Harness Budgets

🌟🌟

工具任务失败后，常见做法是追加规划提示。本文把入口、菜单截断、流程和分派压力分开测试，发现部分问题来自接口限制，修复路由或直接切换配置比提示更有效。失败轨迹中的“未完成义务”却难以定位真实原因。它提醒开发者先做受控复现，别把接口修复后的涨分解释成模型学会了规划。

[阅读论文 PDF](https://arxiv.org/pdf/2610.21098)

### 把真实任务的缺项和歧义加入智能体评测

AgentPerturb: Evaluating LLM Agent Robustness under Controlled Interaction Perturbations

🌟🌟

标准任务通常把需求说得很完整，真实用户则会漏条件、混用概念或夹带干扰。本文在固定框架下加入十二类扰动，观察十个模型的执行与问题识别能力，发现成功率退化而主动发现缺口并不常见。它适合补充产品验收；任务数有限且未测试复合噪声，不能把榜单顺序当作所有真实场景的可靠性排名。

[阅读论文 PDF](https://arxiv.org/pdf/2610.21624)

### 训练小型审计智能体，主动寻找策略违规路径

PROBE: Learning to Audit Policy Compliance in Tool-Using LLM Agents

🌟🌟

安全审计需要主动走到违规路径，随机提问往往覆盖不足。本文训练小型审计智能体，结合严重度、去重和任务进度奖励，在二十类政策中发现十二类违规，超过更大零样本模型。实验只有两个环境与单训练检查点，行动又高度集中于搜索；确定性检查器还可能漏掉语义风险，不能据此认定覆盖了高危行为。

[阅读论文 PDF](https://arxiv.org/pdf/2610.22124)

### 群聊里没公开附和，也可能已被错误信息带偏

Believed but Not Said: Measuring Hidden Belief Collapse in Multi-Agent LLM Discussions

🌟🌟

多智能体讨论是否能靠人数抵抗错误信息？论文在十人讨论中加入少数传播错误事实的成员，发现最终错误率明显增加，私下回答被带偏的程度又高于公开附和。它提示只监控聊天记录会漏掉部分污染。这里的“私下信念”只是带历史条件的回答，仍受探针与裁判影响，不能直接理解为模型内部心理状态。

[阅读论文 PDF](https://arxiv.org/pdf/2610.22138)

### 只看最终答案，会漏掉记忆系统的过程退化

Beyond Downstream QA: Rethinking How We Evaluate Agent Memory

🌟🌟

长期记忆是否退化，未必能从最后一个答案看出来。本文用三十条可操作轨迹检查六类记忆演化，发现过程指标与终局成绩常有分歧，平均差约16个百分点。它适合作为系统诊断，帮助定位知识何时被覆盖或扭曲；样本规模小、只覆盖一种记忆系统，部分评分也依赖模型，暂不适合承担通用排名。

[阅读论文 PDF](https://arxiv.org/pdf/2610.22209)

## 应用与基准

### 客户把需求全说清，也不能保证交付稳妥

FDE-Gym: The Last Mile of AI Delivery

🌟🌟🌟

交付型智能体不仅要完成技术任务，还要发现约束并控制沟通成本。论文在九十五项原始客户请求任务上，最佳配置平均得分0.56，只有十四项达到较高完成度且无事故。拿齐关键事实也未必交付有效系统；场景包含大量变体，沟通成本由专家设定，又缺少人类基线，暂不能推算真实替代比例。

[阅读论文 PDF](https://arxiv.org/pdf/2610.22350)

### 机器学习工程智能体的提升，要连同实验预算一起读

MLExpert: Towards a Generalist Agentic Model for Autonomous Machine Learning Engineering

🌟🌟

机器学习工程智能体既要写代码，也要等待实验并调整方案。本文结合专用框架、监督数据和实验窗口强化学习，在二十二项竞赛子集把获奖比例由37.9%提高到72.7%。但每项允许十二小时和专用大显存加速卡，部分前沿对照只运行一次。读者应同时比较模型、框架、重复次数和实验资源，而非只看获奖率。

[阅读论文 PDF](https://arxiv.org/pdf/2610.22344)

### 环境不会等模型想完：把慢教师留在离线练习中

The World Won't Wait: Evaluating and Teaching Agents Under a Live Clock

🌟

实时环境中，回答更准确未必行动更有效。论文让游戏在模型思考时继续运行，再由慢教师离线试错、快学生检验，把经验压成部署规则。六类游戏的测试平均分由13.51升至24.19。它依赖可重置环境和结构化观测，其他优化器的预算也未完全匹配，暂不支持普遍优越性的判断。

[阅读论文 PDF](https://arxiv.org/pdf/2610.20665)
