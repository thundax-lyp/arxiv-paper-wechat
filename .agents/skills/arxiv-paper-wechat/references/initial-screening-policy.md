# 标题粗筛规范

本阶段位于 `list.json` 与 PDF 下载之间，目标是排除标题已明显不属于 Agent / LLM 简报范围的论文，减少无效下载与转换。它不是正式编辑、taxonomy 分类或评分。

逐篇只读取 `title`，输出：

```json
{ "arxivId": "2609.12345", "decision": "download", "reason": "标题直接表明研究 LLM 工具调用。" }
```

- `skip`：仅用于标题已明确是纯 CV、传统机器人控制、图学习、优化、普通 NLP 任务，且看不出 LLM/Agent 方法关联的论文。原因必须说明标题显示的领域或任务，不能只写“不相关”。
- `download`：标题直接涉及 Agent、LLM、语言模型、推理、RAG、工具使用、对齐、评测或安全时保留；标题含糊、缩写难判或可能相关时也保留，宁可多下载，不得因不确定而跳过。
- 不在本阶段阅读摘要、PDF 或作者信息；不输出方向、标签、分数或正式评价。
- 输入必须覆盖 `list.json` 的每篇论文恰好一次。CLI 将结果原子写回每篇论文的 `screening` 字段；随后下载命令只处理 `decision: "download"` 的论文。
