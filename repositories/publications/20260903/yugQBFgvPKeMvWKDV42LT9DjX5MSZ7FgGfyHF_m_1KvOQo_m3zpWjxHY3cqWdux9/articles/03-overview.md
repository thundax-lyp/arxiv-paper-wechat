### [1] 用于本地检索增强工厂智能体的测量驱动子网络选择

> **原标题：** Measurement-Driven Sub-Network Selection for On-Premise Retrieval-Augmented Factory Agents

- **评分：** 8/10
- **作者/机构：** 作者机构未在已核查正文中明确标注
- **关键词：** LLM、Agent

**📌 研究问题与结论**  
研究按适配后的回答质量、实测端侧吞吐、能力下限和内存预算选择工厂 RAG Agent 的子网络，而非仅按参数量压缩。

**🔧 方法与系统**  
训练共享权重超网络，以夹心式原位蒸馏得到子网络；再按每台设备的质量与吞吐测量做受约束选择。

**💡 核心创新**  
把 RAG 适配后的质量纳入后训练子网络选择，说明参数量不能直接代表部署答案质量。

**🏋️ 训练与数据**  
在制造说明书场景做结构压缩、检索接地蒸馏和三档异构边缘设备测试。

**📊 结果与证据**  
剪枝造成原模型评判质量 13.7% 的损失，检索蒸馏将差距缩至 4.6%；三类设备待机功耗为 1.3–5W。

**🧐 编辑点评**  
制造手册案例把部署指标落到实测硬件，但指标含 LLM 评判，结论能否迁移到其他知识域仍待验证。

**⭐ 为什么值得读**  
适合受限硬件上的私有 RAG 助手；应以本域专家评估补充自动评判。

[arXiv 原文](https://arxiv.org/abs/2609.02760) · [PDF](https://arxiv.org/pdf/2609.02760)

### [2] 学习基于证据的多跳问答选择性回答边界

> **原标题：** Learning Evidence Sufficiency Boundaries for Selective Answering in Grounded Multi-Hop QA

- **评分：** 7/10
- **作者/机构：** Haruto Sato、Yuki Tanaka、Ren Nakamura、Aoi Kobayashi、Mei Ito；机构未披露。
- **关键词：** selective-answering、evidence-sufficiency、abstention

**📌 研究问题与结论**  
ESBT 把拒答学习改为同一问题在证据由不足到充分时的边界学习，改善何时开始回答的定位，但并未全面胜过 token 级拒答基线。

**🔧 方法与系统**  
将每题构成无支持、部分支持、最小充分、冗余充分四级上下文；结合级别交叉熵、边界翻转 margin、充分证据后稳定损失与回答召回保护，生成答案或 ABSTAIN。

**💡 核心创新**  
用同一问题的有序证据链直接监督拒答到回答的局部转折，并新增边界指标。

**🏋️ 训练与数据**  
HotpotQA、2WikiMultiHopQA、MuSiQue 各 800 个问题族，共 9,600 链式样本；Qwen2.5-3B-Instruct、LoRA rank 16，400 步，单种子，上下文预算 1,400 字符。

**📊 结果与证据**  
§6：翻转准确率 0.807 对比 SEAL-style 0.781，外部不可答集无依据回答率 0.095 对比 0.101；原始 QA F1 为 0.584 对比 0.590，后边界稳定性 0.719 对比 0.904，显示收益与退步并存。

**🧐 编辑点评**  
同源问题族比较有利于隔离监督格式作用，且同时报告误拒答和回答效用。只有一个 3B 骨干、一个训练种子，自动证据验证及判分缺人工核验；后边界稳定性明显弱于 SEAL-style，微小的外部无依据回答率差距缺乏多种子统计支撑。

**⭐ 为什么值得读**  
适合设计 RAG 拒答测试的读者，证据逐级补齐的评测方式比只统计拒答率更有诊断价值。

[arXiv 原文](https://arxiv.org/abs/2609.01687) · [PDF](https://arxiv.org/pdf/2609.01687)

### [3] ArcticSwarm：延后长程多智能体研究的过早共识

> **原标题：** ArcticSwarm: Deferring Early Consensus in Long-Horizon Multi-Agent Research

- **评分：** 8/10
- **作者/机构：** Soyoung Yoon、Boyi Liu、Yite Wang、Ruofan Wu、Canwen Xu、Nikki Lijing Kuang、Seung-won Hwang、Yuxiong He、Zhewei Yao；机构未确认。
- **关键词：** multi-agent、deep-research、independent-search

**📌 研究问题与结论**  
ArcticSwarm 将独立搜证与共享整合分开，通过任务级公告板读取限制和提交前审查减少多Agent过早接受同一候选的现象。

**🔧 方法与系统**  
Agent均可发布证据，但隔离任务不能读同伴发现；自检、持续公告板审查及最终门槛要求独立审查者/已完成任务者核验，并运行至少一个替代候选任务。

**💡 核心创新**  
按搜证任务控制同伴信息读取，把多来源审查放在候选承诺前，而非仅增加并行样本。

**🏋️ 训练与数据**  
不微调；BrowseComp-Plus 830题、约10万文档，Qwen3.5-27B主实验三次运行；实时BrowseComp 1,266题，GPT-5等扩展，工具、截止、并发上限等对齐对照。

**📊 结果与证据**  
§5：主系统82.6±0.5%，去隔离78.8%，再去结构审查74.5%，对齐MiroFlow70.6%；去三项审查但保留隔离76.3%。实时GPT-5为73.6%，属于含额外工具与容错工程的整套系统结果。

**🧐 编辑点评**  
固定语料、开源模型三次运行、隔离和审查消融及对齐MiroFlow构成较强证据；不同架构实际token不同，不能解释为固定计算预算效率。实时网页与供应商历史分数不可完全控制，审查仍可共同接受错误候选，软截止也会放松门槛。

**⭐ 为什么值得读**  
适合搭建多Agent研究系统的读者，尤其看信息读取边界、候选替代搜索和审查成本的消融。

[arXiv 原文](https://arxiv.org/abs/2609.01870) · [PDF](https://arxiv.org/pdf/2609.01870) · [代码](https://github.com/Snowflake-AI-Research/ArcticSwarm)

### [4] 认知层面的女巫攻击抵抗：增加 AI 智能体而不增加证据

> **原标题：** Epistemic Sybil Resistance: Multiplying AI Agents Without Multiplying Evidence

- **评分：** 7/10
- **作者/机构：** Marc Bara；作者机构未确认。
- **关键词：** multi-agent、provenance、uncertainty

**📌 研究问题与结论**  
论文区分报告数量和独立证据数量，证明仅凭报告内容无法普遍识别复制形成的虚假佐证，并用受控 LLM 实验展示忽略共同来源导致的过度自信。

**🔧 方法与系统**  
以条件互信息定义新增信息，推导共享证据根与相关提取误差下的高斯聚合精度上界；对固定来源增加报告、固定报告增加独立来源，并比较相似度去重。

**💡 核心创新**  
将多 Agent 的重复佐证问题转化为证据血缘与依赖结构问题，给出无法只靠输出解决的识别边界。

**🏋️ 训练与数据**  
不训练模型；逾两万次受控调用，100 个独立校准世界、300 个评估世界，来源文档是人工可控的合成任务。代码承诺公开，正文无可核验仓库链接。

**📊 结果与证据**  
§8：单一来源报告从 1 增至 32，朴素聚合的名义 95% 区间覆盖率从 0.940 降至 0.263，来源感知方法维持 0.850–0.940；16 份报告各有独立来源时两者覆盖率同为 0.927。

**🧐 编辑点评**  
理论与来源数量干预相互支持，但实验限于单个小模型和合成营收计算。预注册信息量门槛未达到而仍保留实验；相关误差修正是在观察评估偏差后选择的探索性分析。来源记录本身不保证真实或独立。

**⭐ 为什么值得读**  
适合设计多 Agent 汇总、投票和置信度系统，尤其需要防止多个输出重复引用同一证据的团队。

[arXiv 原文](https://arxiv.org/abs/2609.01873) · [PDF](https://arxiv.org/pdf/2609.01873)

### [5] MASkills：面向多智能体 LLM 系统的持续技能优化

> **原标题：** MASkills: Continual Skills Optimization for Multi-Agent LLM Systems

- **评分：** 7/10
- **作者/机构：** 作者机构未确认；研究获得 Cisco、Amazon 与 NSF 部分资助。
- **关键词：** agent-skills、multi-agent、continual-learning

**📌 研究问题与结论**  
MASkills 从显式 Skill 调用轨迹分配文字反馈，逐轮修改、归纳、合并和裁剪多 Agent 技能库，并通过验证集验收或回滚候选修改。

**🔧 方法与系统**  
按 Skill 调用做语言批评，在轨迹、技能和 Agent 层次聚合，结合历史修改方向生成新版本；固定其他 Agent 的技能验证当前修改，低于容差则回滚。

**💡 核心创新**  
以可执行、可逐步加载的技能产物作为优化单位，并把版本验收与回滚纳入经验进化。

**🏋️ 训练与数据**  
不更新演员模型权重；GPT-5.1 优化 Skill，GPT-4o-mini 执行 HotpotQA/LoCoMo，Qwen2.5-7B 执行 GAIA。

**📊 结果与证据**  
主表 HotpotQA F1=76.3，对 MultiPersona 69.2；GAIA 平均成功率 23.3%，R1-Searcher 20.4%。去掉验证回滚后 GAIA 降至 13.5%，LoCoMo 多跳 F1 从 17.2 降至 6.6。

**🧐 编辑点评**  
文字梯度、优势和动量是类比，不是可微优化或真实反事实效应。样本划分、预算和重复运行细节交代有限；持续复用验证集的选择偏差及强优化器成本需要独立检查。最难 GAIA L3 仍为零。

**⭐ 为什么值得读**  
适合研究 Skill 自动维护的团队，优先复现候选版本隔离、独立评估与回滚，再评估文字归因模块的增量价值。

[arXiv 原文](https://arxiv.org/abs/2609.02094) · [PDF](https://arxiv.org/pdf/2609.02094) · [代码](https://github.com/DaRL-GenAI/MASkills)

### [6] AI 智能体重塑人类群体的共识形成

> **原标题：** AI agents reshape consensus formation in human groups

- **评分：** 7/10
- **作者/机构：** 研究经清华大学伦理审查；完整作者机构未确认。
- **关键词：** human-ai、consensus、group-dynamics

**📌 研究问题与结论**  
真实参与者与 AI 共同描述同一图形的实验发现，AI 比例与群体表述收敛并非单调关系，高比例时共识更趋向 Agent 的表达。

**🔧 方法与系统**  
八条件中随机配对交流 40 轮，改变 AI 比例并在固定比例下操纵采纳或坚持倾向，分析表达相似度、采纳与持续性。

**💡 核心创新**  
同时考察共识强度和共识内容来自谁，而不只看人机团队是否达成一致。

**🏋️ 训练与数据**  
不训练模型；主模型 Qwen2.5-VL-32B，7B 作能力对照；AI 比例 0/12.5/33.3/50/75%，另有行为提示干预。

**📊 结果与证据**  
纯人类平均相似度 0.695，12.5% AI 条件提高约 8%，33.3% 下降约 23.1%，75% 回升到 0.725；这些是本实验条件的观察，不是可直接采用的团队配比。

**🧐 编辑点评**  
127 名参与者来自中国高校、英语任务、一个图形和单一模型家族；每条件为 24 人机成员群组，缺少独立群组重复，个体及配对表达并非独立样本。嵌入相似度同时决定奖励和共识指标，不能直接外推社会观点或真实规范形成。

**⭐ 为什么值得读**  
适合研究人机协作与多 Agent 社会影响的读者，优先关注群组重复、身份透明和指标诱导效应。

[arXiv 原文](https://arxiv.org/abs/2609.02122) · [PDF](https://arxiv.org/pdf/2609.02122) · [代码](https://github.com/tsinghua-fib-lab/human-ai-consensus)

### [7] Codebook Agent：LLM 多智能体系统的摊销式拓扑设计

> **原标题：** Codebook Agent: Amortized Topology Design for LLM Multi-Agent Systems

- **评分：** 7/10
- **作者/机构：** 作者机构未在已核查正文中明确标注
- **关键词：** LLM

**📌 研究问题与结论**  
Codebook Agent 先学少量可用通信拓扑，按查询选择并以实际效用和 token 成本重排。

**🔧 方法与系统**  
向量量化压缩拓扑，查询 MLP 预测代码，读取展开邻接矩阵的代理模型预测实测收益和 token 成本。

**💡 核心创新**  
不把边数直接当成本，以少量候选代替在线迭代图搜索。

**🏋️ 训练与数据**  
冻结 gpt-4o-mini，训练码本与代理；六个推理/代码基准，另用 Qwen3-8B 验证。

**📊 结果与证据**  
六基准均值 84.6 对强基线 83.0；设计轴比较减少 21.9%–33.2% token，MATH 端到端 43.7→27.4 分钟。

**🧐 编辑点评**  
每配置仅一次评测；2.4 毫秒是拓扑生成而非 Agent 端到端。将同特征节点的结构不变性推广至一般 sum 聚合过强，节点度数可改变求和结果；六个有效代码也仅是采样范围观察。

**⭐ 为什么值得读**  
适合多智能体成本优化，需复核真实 token、完整延迟及不同角色设置。

[arXiv 原文](https://arxiv.org/abs/2609.02264) · [PDF](https://arxiv.org/pdf/2609.02264) · [代码](https://github.com/jinxiy1104/CodebookAgent)

### [8] 输出格式如何混淆指令微调的数据质量与能力

> **原标题：** How Output Format Confounds Data Quality and Capability in Instruction Tuning

- **评分：** 8/10
- **作者/机构：** 作者机构未确认。
- **关键词：** instruction-tuning、evaluation、format-confound

**📌 研究问题与结论**  
研究发现输出格式同时干扰训练数据质量评分和微调能力评测：同内容换格式可能让收益难以迁移，生成长度预算也能反转微调效果的正负。

**🔧 方法与系统**  
在十二任务、四种语义等价格式下提取归一化 LoRA 梯度，比较谱统计、共识与残差方向；构造标签和表面扰动，检验跨格式学习及生成预算影响。

**💡 核心创新**
