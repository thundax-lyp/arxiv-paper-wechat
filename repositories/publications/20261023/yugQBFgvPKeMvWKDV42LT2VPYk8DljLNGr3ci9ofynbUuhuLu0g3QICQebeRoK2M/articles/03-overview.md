# arXiv Agent 与大模型研究简报｜2026-10-23｜入选论文全览 2/2

本期集中关注智能体如何在长期运行中保持可核验、可恢复和可控：从协作结构、工具协议与记忆治理，到编码基准、研究诚信和安全监控。另有推理预算、个性化、检索与多智能体反馈的实证结果。

本期入选论文全览。

## 应用与基准

### 个人智能体为何总记不住用户希望怎样被协助

Why Bother Me Again? Benchmarking Personal Agent Memory for Interaction Preferences

🌟🌟🌟

个人智能体记忆基准 不只考事实回忆，而是考个人智能体何时应询问、确认或直接行动。现有检索记忆未优于无记忆，文件式记忆虽提高命中却容易跨场景误用偏好。长程变化和行为评分有价值；用户是模拟的，只有四个档案，真实烦扰成本尚未校准。

[阅读论文 PDF](https://arxiv.org/pdf/2610.30485)

### 银行智能体完成结果之外还必须遵守流程

TauIndianBankBench: Procedure-Aware, Action-Oriented Evaluation of Tool-Using Conversational Agents

🌟🌟

印度银行流程基准 用一千项零售银行任务同时检查最终状态和必需过程，证明只看记录结果会把跳步或未授权修改误判为成功。规模与确定性评分较强；规则由特定银行流程抽象，真实政策与用户行为更复杂。

[阅读论文 PDF](https://arxiv.org/pdf/2610.30161)

### 移动界面智能体的个性化究竟错在哪一步

Diagnosing Personalization Failures in Mobile GUI Agents

🌟🌟

偏好诊断基准 将移动 图形界面 偏好分成五类，并沿执行阶段定位“何时应用”和“如何改变动作”的错误，揭示总成功率掩盖的个性化失败。诊断覆盖较好；移动环境和偏好集合有限，模拟任务未必反映真实用户修正。

[阅读论文 PDF](https://arxiv.org/pdf/2610.30573)

### 个人历史如何帮助智能体寻找并使用外部知识

ColaBench: Evaluating Memory-Guided Knowledge Acquisition in Personal Agents

🌟🌟

个人知识获取基准 评估个人智能体能否从历史条件推断当前需要的外部知识，并把知识正确应用到用户处境。结果把记忆检索与知识获取的失败分开。任务链条设计贴近个人助手；合成档案、自动评估与固定知识库限制外部有效性。

[阅读论文 PDF](https://arxiv.org/pdf/2610.30989)
