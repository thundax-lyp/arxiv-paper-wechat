### [1] 无需内部信号的 Web 智能体监测：可观测轨迹与关键步骤监督

> **原标题：** Monitoring Web Agents Without Internal Signals: Observable Trajectories and Key-Step Supervision

- **评分：** 8/10
- **作者/机构：** 作者机构未确认。
- **关键词：** agent-monitoring、failure-prediction

**📌 研究问题与结论**  
论文用可见动作、反馈和重复决策采样预测 Web Agent 当前轨迹风险，并从最终失败中标出尚未被纠正的关键错误，避免把有效早期步骤一并标成失败。

**🔧 方法与系统**  
31 个宏观日志特征加 18 个意图、动作、预期状态一致性特征，训练 L2 逻辑回归；由 LLM 辅助标注关键步骤，按任务分组五折验证。

**💡 核心创新**  
将风险监督对齐到失败演化时间，并区分无需调用的日志信号与额外黑箱探测信号。

**🏋️ 训练与数据**  
两个 Web 基准、五个骨干共 2183 条轨迹；150 条人工标注对照，关键步骤相差不超一步占 80%，前缀标签一致性 89.8%。

**📊 结果与证据**  
§4 在 20% 成功轨迹误切预算下，两基准失败检测率约 44.3% 与 44.5%；Micro 在 Mind2Web 有一致增益，在 WebArena-Lite 无稳定增益。

**🧐 编辑点评**  
关键错误是完整轨迹下的事后标签，不是客观不可恢复状态；提前切断仅离线模拟，未证明实际干预提升成功率。Micro 每步十次采样有额外成本，最佳检测率仍伴随不低误切率。

**⭐ 为什么值得读**  
适合做 Agent 运行监控的团队，可先复现低成本 Macro 方案，再评估重复采样是否值得。

[arXiv 原文](https://arxiv.org/abs/2609.02057) · [PDF](https://arxiv.org/pdf/2609.02057)

### [2] ToolGate：依赖工具的科学基准构建可执行验收流水线

> **原标题：** ToolGate: An Executable Acceptance Pipeline for Tool-Dependent Scientific Benchmark Construction

- **评分：** 8/10
- **作者/机构：** 加利福尼亚大学河滨分校。
- **关键词：** benchmark-construction、tool-use、validation

**📌 研究问题与结论**  
ToolGate 让科学题目依次通过脚本复算、无工具筛除和独立工具求解，但审计发现大量通过项仍含领域计算错误，鲜明展示“可执行一致”并不等于题意正确。

**🔧 方法与系统**  
生成题目、选项和解题脚本，独立执行复算；对随机选项排列进行三次无工具测验，再让隐藏参考解的工具 Agent 独立求解，保存所有门控记录。

**💡 核心创新**  
把生成候选与接受候选分离，并公开协议修正、题目集中度和门控漏检的证据。

**🏋️ 训练与数据**  
不训练模型；五个专家种子、500 次 FEniCSx 生成，GPT-5.5 中等推理生成和工具求解，每次上限 300 秒；后加跨模型及更强无工具筛查。

**📊 结果与证据**  
478 项通过脚本复算，三道无工具筛查后余 135，工具求解成功 130，去重 128；但语义审计发现上述大量布局问题。原生成消耗 29.4 agent-hour，不是与人工成本的受控比较。

**🧐 编辑点评**  
130 个去重前通过项中，97 个受同一种 FEniCSx 数据布局缺陷影响、五个未决；128 个去重结果只能称协议通过项，不能当作已验证高质量题库。工具与无工具条件同时改变脚手架，不能归因于工具单一作用。

**⭐ 为什么值得读**  
适合自动测试和基准构建者，重点参考如何为题意与领域计算增加独立验收，而非把三个门通过视为充分保证。

[arXiv 原文](https://arxiv.org/abs/2609.02067) · [PDF](https://arxiv.org/pdf/2609.02067)

### [3] 用推理时算力与部署脚手架提升评测真实性

> **原标题：** Improving Evaluation Realism with Inference-Time Compute and Deployment Scaffolds

- **评分：** 8/10
- **作者/机构：** 作者机构未在已核查正文中明确标注
- **关键词：** LLM

**📌 研究问题与结论**  
研究用额外推理预算修订模拟审计动作，并用真实编码 Agent 外壳改善评测环境的可信度。

**🔧 方法与系统**  
Petri 审计中比较候选动作并迭代批评；DISH 对齐部署系统提示、工具与提醒。

**💡 核心创新**  
同时处理模拟内容和运行外壳，并以真实会话重建区分任务与环境逼真性。

**🏋️ 训练与数据**  
不训练目标模型；50 个抽样种子、编码种子及其改写、50 条真实任务重建，65 条人工标注校准意识评委。

**📊 结果与证据**  
普通审计中两方法可叠加，但真实任务重建时组合不稳定；部分目标最佳逼真胜率仍低于 20%，GPT-5.5 种子遵循度 .92→.72。

**🧐 编辑点评**  
逼真性由模型评委与目标辨别度代理衡量，不能证明模型没有暗中识别测试；目标模型参与反馈和选择还存在串通面。预算基线实际花费未完全匹配。

**⭐ 为什么值得读**  
适合构建 Agent 安全评测，需同时记录逼真性、任务遵循和异常行为指标。

[arXiv 原文](https://arxiv.org/abs/2609.02302) · [PDF](https://arxiv.org/pdf/2609.02302) · [代码](https://github.com/meridianlabs-ai/petri_dish)

### [4] WinoQueer-NL：评估荷兰语模型对 LGBTQ+ 身份的偏见

> **原标题：** WinoQueer-NL: Assessing Bias in Dutch Language Models toward LGBTQ+ Identities

- **评分：** 8/10
- **作者/机构：** 作者机构未在已核查正文中明确标注
- **关键词：** LLM

**📌 研究问题与结论**  
WinoQueer-NL 将英语酷儿偏见评测经荷兰语与文化校准，形成 42,906 个反事实句对，并评估荷兰语与多语语言模型的身份组别差异。

**🔧 方法与系统**  
翻译并人工审核原始谓词，调查荷兰 LGBTQ+ 受访者的相关性与伤害性，加入本地偏见，再以成对句子对数似然比较测量偏向。

**💡 核心创新**  
把社区验证和本地新增刻板印象纳入非英语语言模型偏见基准，而非直接翻译英语数据集。

**🏋️ 训练与数据**  
无训练；对 13 个荷兰语或多语掩码与自回归模型评测。

**📊 结果与证据**  
总体加权均值接近 50%，但身份组差异很大：跨模型的跨性别与非二元身份分数更高；伤害性与偏见强度相关极弱（|r| 小于 0.12）。

**🧐 编辑点评**  
社区参与提升了文化贴合度，但仅 43 名受访者且模板结构限制能表达的偏见类型；似然分数也不能证明真实交互中的公平性。

**⭐ 为什么值得读**  
适合荷兰语模型上线前的偏见审计；应结合开放式生成和真实用户测试，避免把低分当作无偏见证明。

[arXiv 原文](https://arxiv.org/abs/2609.02651) · [PDF](https://arxiv.org/pdf/2609.02651) · [代码](https://github.com/jerryspan/WinoQueer-NL/)

### [5] 从词元到语义：利用互补信号检测黑盒 LLM 幻觉

> **原标题：** From Tokens to Semantics: Leveraging Complementary Signals for Hallucination Detection in Black-Box LLMs

- **评分：** 8/10
- **作者/机构：** 作者机构未在已核查正文中明确标注
- **关键词：** LLM

**📌 研究问题与结论**  
该研究用黑盒 API 可见的语义分歧和 token 对数概率检测幻觉，提出跨采样 token 聚合、级联和堆叠分类器，并把误报预算纳入比较。

**🔧 方法与系统**  
对多次生成的语义簇与 token 不确定性取特征，TopK 无监督聚合，Gated 在单簇时路由给 token 分类器，Stacked 联合学习两类特征。

**💡 核心创新**  
针对语义熵在一致但错误回答上失效的情形，把跨响应 token 不确定性作为互补证据，并按固定误报率评估。

**🏋️ 训练与数据**  
在七个基准、四个生成模型上评测；Gated 与 Stacked 使用目标域带标注幻觉数据训练。

**📊 结果与证据**  
26 个模型-数据集比较中，Stacked 领先或并列 11 次，20 次距离最佳 AUROC 不超过 0.05；不同数据集、温度、采样数和误报预算会改变首选方法。

**🧐 编辑点评**  
结论明确承认无通用最优方法；监督方案需要目标域标注，且有小样本 Long-Text QA 和 API 返回候选受限等限制。

**⭐ 为什么值得读**  
适合有人工复核容量的高风险黑盒 LLM 流程；应以本域数据校准阈值并按误报成本选运行点。

[arXiv 原文](https://arxiv.org/abs/2609.02679) · [PDF](https://arxiv.org/pdf/2609.02679)

### [6] 登门槛请求与大语言模型的拒绝行为

> **原标题：** Door-in-the-Face Requests and Refusal Behaviour in Large Language Models

- **评分：** 8/10
- **作者/机构：** 作者机构未在已核查正文中明确标注
- **关键词：** LLM

**📌 研究问题与结论**  
研究测量一次被拒绝后的较小后续请求如何影响模型响应，发现这种顺序效应会随模型家族反向变化，不能泛化为通用安全绕过结论。

**🔧 方法与系统**  
在九个生产模型上比较直接请求、良性前序、相关与无关的先前拒绝，并用项目聚类 bootstrap、符号检验和双判官规则评估。

**💡 核心创新**  
将社会心理学的顺序请求效应作为上下文依赖的拒绝行为测量问题，而非将单次成功率视为固有模型属性。

**🏋️ 训练与数据**  
无训练；60 个构造性判断项目加公共基准中模型自身拒绝的项目。

**📊 结果与证据**  
构造项目中，不同模型家族方向相反；但在基准拒绝项上没有显著正向结果，论文明确指出数据不支持其作为安全绕过方向。

**🧐 编辑点评**  
有直接请求、无关拒绝与多判官控制，但主要证据来自一种英语请求家族，且多数端点为随时间变化的闭源模型。

**⭐ 为什么值得读**  
适合模型安全与拒绝行为评测团队做多轮、按模型版本固定的回归测试；不应据此设计或传播规避策略。

[arXiv 原文](https://arxiv.org/abs/2609.02707) · [PDF](https://arxiv.org/pdf/2609.02707)

### [7] EarlyEval：通过早期结果预测降低智能体评测成本

> **原标题：** EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction

- **评分：** 8/10
- **作者/机构：** 作者机构未在已核查正文中明确标注
- **关键词：** LLM、Agent

**📌 研究问题与结论**  
EarlyEval 由中间轨迹特征预测 Agent 最终成败，在置信度足够时提前停止评测以减少逐任务执行成本。

**🔧 方法与系统**  
以行为、文本和参考解特征训练一对 LightGBM 成功/失败分类器，并用校准阈值触发停止。

**💡 核心创新**  
从压缩评测任务数转向压缩每个 Agent 任务的执行轨迹。

**🏋️ 训练与数据**  
在 SWE-bench Verified、TerminalBench、Toolathlon 的 Agent 轨迹上训练和评测。

**📊 结果与证据**  
论文报告减少 13%–26% 步数，最多减少 44.1% 输入与 29.4% 输出 token；预测准确率 89%–97%，平均 resolve-rate 扰动 1–2 点。

**🧐 编辑点评**  
节省建立在结果可早期预测的基准特性上，提前停止可能改变指标，应持续监控不同 Agent 的 resolve-rate 扰动。

**⭐ 为什么值得读**  
适合昂贵 Agent 基准的迭代评估；应先为每个新任务族独立校准并报告偏差。

[arXiv 原文](https://arxiv.org/abs/2609.02783) · [PDF](https://arxiv.org/pdf/2609.02783)

### [8] SafeEvolve：从智能体经验中协同演化安全框架与策略

**🔧 方法与系统**

### [9] ClaimReceipt：验证智能体评测中的证据充分性与覆盖度

> **原标题：** ClaimReceipt: Verifying Evidence Sufficiency and Coverage in Agent Evaluations

- **评分：** 7/10
- **作者/机构：** Peiying Zhu、Sidi Chang；Blossom AI、Blossom AI Labs。
- **关键词：** agent-evaluation、evidence、audit

**📌 研究问题与结论**  
ClaimReceipt 将评测证据分为完整性、声明所需语义、已承诺实验覆盖和外部真实性，按每条结论返回通过、无效或证据不足，避免把有日志误当作可验证。

**🔧 方法与系统**
